# Sync Brain

Use this workflow when the user invokes `/sync`.

1. Load and follow `.agents/skills/sync-engram/SKILL.md`.
2. Identify the current or named session and load minimal relevant context.
3. Detect durable changes and classify each claim by type and provenance.
4. Search for existing canonical pages before proposing new ones.
5. Present semantic changes in a compact proposal, separate from safe maintenance.
6. Wait for approval and apply only the approved semantic scope.
7. Preserve raw payloads and evidence.
8. After approved writes, maintain real links, reciprocal backlinks only between editable derived pages, the complete navigable-corpus `Engram/INDEX.md`, a policy-conforming `Engram/LOG.md`, and non-semantic metadata without a second material approval. Never edit an immutable raw manifest to add a backlink.
9. Report results, conflicts, and open questions.
10. For a high-impact completed Sync, optionally propose `/checkpoint`; never commit implicitly.
