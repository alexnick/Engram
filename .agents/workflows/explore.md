# Explore

Use this workflow when the user invokes `/explore`.

1. Load and follow `.agents/skills/explore/SKILL.md`.
2. Determine the target from command text, a named capture, project, source, or the current discussion.
3. Load minimal context through `CONTEXT-MAP.md`, `Engram/INDEX.md`, and relevant pages.
4. Treat the explicit Explore request as narrow authorization to create and update its temporary non-authoritative structured session note.
5. Do not treat that authorization as approval for durable semantic promotion.
6. Ask one high-value question at a time and keep claim types distinct.
7. At a natural stopping point, provide the structured synthesis with real Markdown citations.
8. Propose Sync only when durable impact is high; do not write semantic conclusions directly.
