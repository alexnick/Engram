# Capture

Use this workflow when the user invokes `/capture`.

1. Load and follow `.agents/skills/capture/SKILL.md`.
2. Use text following the command as the capture. If absent, use the clearly identified thought from the current message or conversation.
3. Ask one clarification only if the target cannot be determined.
4. Save the exact payload in a new Raw Capture or append it as a separately dated Additional Raw Capture to an obvious duplicate.
5. Perform safe corpus-index, permitted processing-reference, metadata, and policy-conforming log maintenance without changing payload meaning.
6. Return the path and title.
7. Do not create, propose, stage, or commit a Git checkpoint merely because Capture completed.
