# Keeper / Brain — короткий старт

Keeper — это личная память в Markdown-файлах, с которой помогает работать AI-агент. Чат временный; важное нужно явно сохранить в Brain.

## Как начать в Antigravity

1. Открой папку repo в Antigravity.
2. Напиши агенту:

   ```text
   Прочитай AGENTS.md и QUICKSTART-RU.md. Помоги мне начать пользоваться Brain.
   ```

3. Для первого теста сохрани мысль:

   ```text
   /capture Это мой первый тестовый capture.
   ```

4. Спроси, что сохранилось:

   ```text
   /query Что Brain знает о моём первом тестовом capture?
   ```

## Самые полезные команды

### `/capture` — быстро сохранить дословно

Используй, когда важно не потерять мысль:

```text
/capture Мне пришла идея для проекта: ...
```

Capture сохраняет сырой текст как evidence. Он не обязан быть фактом, решением или окончательной позицией.

### `/query` — спросить из Brain

```text
/query Что я уже сохраняла про работу?
```

Query ничего не меняет, только ищет и отвечает по сохранённым файлам.

### `/explore` — подумать вместе

```text
/explore Я хочу понять, как мне лучше вести личные проекты.
```

Explore помогает развить мысль. Сам по себе он не делает выводы вечными.

### `/sync` — сохранить выводы надолго

После обсуждения скажи:

```text
/sync
```

Агент предложит, что записать в Brain. Он должен сначала показать proposal. Запись важных выводов делается только после твоего явного одобрения.

### `/review` — разобрать накопившееся

```text
/review
```

Показывает необработанные captures и предлагает, что с ними сделать.

### `/lint` — проверить порядок

```text
/lint
```

Проверяет структуру, ссылки и возможные проблемы. Read-only.

### `/checkpoint` — Git-точка возврата

```text
/checkpoint
```

Используй после важных изменений. Агент не должен коммитить скрыто.

## Важные правила

- Не редактируй `Brain/INDEX.md` руками — он генерируется.
- Сырой capture не переписывается задним числом.
- Если агент хочет изменить важные знания, решения или контекст, он должен сначала показать proposal.
- `Feedback/TESTING-LOG.md` — место для замечаний о продукте: что непонятно, что не работает, чего не хватает.
- Если не знаешь команду, просто пиши обычным языком: агент должен сам выбрать подходящий workflow.

