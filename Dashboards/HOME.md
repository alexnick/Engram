## Operating Loop

```mermaid
flowchart TD
    C[Capture exact wording] --> Raw[Immutable raw evidence]
    X[External source] --> I[Ingest]
    I --> Raw
    I --> P[Derived source proposal]
    P -->|Approved| D[Derived source record]
    Raw --> E[Explore]
    E --> S[Sync proposal and approval]
    D --> S
    S --> Wiki[Maintained knowledge and context]
    Q[Query] --> Wiki
    R[Review] --> Raw
    R --> S
    L[Lint] --> Wiki
    L --> Raw
    Wiki --> CP[Checkpoint proposal]
    CP --> Git[Approved Git checkpoint]
```

## Safe Defaults

- Capture and explicit Ingest requests preserve raw input immediately.
- Derived source claims and warranted canonical integration require proposal and approval.
- Query, Review reports, and Lint are read-only.
- Sync requires approval before semantic writes.
- Checkpoint defaults to `propose`; it never commits implicitly.
- Git provides rollback; the Log provides operation search.
